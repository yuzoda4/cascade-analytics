Privacy policy - youtube-cascade-analytics

This tool is used only by the owner of the connected YouTube channels.

  • It requests read-only access to YouTube data and YouTube Analytics for the owner's own channels.
  • The data is used only to review the owner's own channel performance. It is stored only on the owner's own computer.
  • No data is sold, shared with third parties, or used for advertising.
  • Access can be removed at any time from the Google Account permissions page.

Contact: please open an issue in this site's GitHub repository.
